# ジットク MVP v0.4

「電卓はめんどう、Excelはおおげさ。」な計算を、入力するだけですぐ終わらせる軽量Webツール集です。

## MVPで動く5ツール

1. かんたん割り勘
   - 複数の会、参加者、合計金額、立替者をまとめて精算
   - 最後に「誰が誰へ何円払えばいいか」を表示
2. レシピ倍率変換
   - 元の人数から作りたい人数へ材料を一括変換
   - 小数・分数入力、材料追加・削除、結果コピー対応
3. 時給換算
   - 対象月、1日の労働時間、勤務日数、手取り額から実質時給を計算
   - 勤務日数は対象月の月〜金の日数を初期表示
4. 今月お金足りる？
   - 現在残高と今後の入出金予定から残高推移を計算
   - 最初に不足する日、不足額、今月を乗り切るための最低必要額を表示
5. 何日働けば買える？
   - 欲しいものの価格、時給、1日の労働時間から必要労働時間・日数を計算

## 共通UI

- メニュー検索
- 選択したツールだけ表示
- スマホ対応

## 方針

- HTML / CSS / JavaScriptのみ
- Webフォントなし
- 外部ライブラリなし
- 画像なし
- DBなし
- 外部通信なし
- アニメーションほぼなし

`index.html` をブラウザで開くだけで動きます。
