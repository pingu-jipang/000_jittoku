# ジットク v0.6 — 個別URL / SEO構造版

「電卓はめんどう、Excelはおおげさ。」な計算を、入力するだけですぐ終わらせる軽量Webツール集です。

## v0.6の変更

- 5ツールをそれぞれ独立URL化
  - `/warikan/`
  - `/recipe/`
  - `/hourly-wage/`
  - `/cashflow/`
  - `/work-to-buy/`
- 各ページに固有の`title`・`meta description`・H1・短い説明文を設定
- トップと各ツールページに検索窓を維持
- ツールをクリックすると、そのツールだけのページを表示
- `robots.txt` と `sitemap.xml` を追加
- HTML / CSS / JavaScriptのみ。外部ライブラリ・画像・DB・外部通信なし

## GitHubへ更新するとき

このZIPの**中身をフォルダごと全部**リポジトリ直下へアップロードしてください。
以前の4ファイルだけでなく、5つのツール用フォルダと`robots.txt`、`sitemap.xml`も必要です。

## 独自ドメインを取得したら

`sitemap.xml` と `robots.txt` 内の `https://000-jittoku.pages.dev` を新しいドメインへ変更してください。
