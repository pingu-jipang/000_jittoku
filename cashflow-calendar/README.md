# ジットク：資金繰りカレンダー v2（日別版）

既存の「今月お金足りる？」（`/cashflow/`）とは別の、6つ目のツール（`/cashflow-calendar/`）。

## 入力順

1. ユーザー・口座名を入力（初期値：オレ、ミク、家族口座。追加・編集・削除可能。最大20件）
2. 各ユーザー・口座の残高とその基準日を入力
3. 年月日、ユーザー・口座、名称、±、金額を行ごとに追加（最大2,000件）
4. 「カレンダーで確認する」で日付ごとの予想残高を表示（0円以上＝緑、マイナス＝赤）

カレンダーでは合計と各ユーザー・口座を切替可能。マイナスの日は不足額を計算し、日付をタップすると正確な円額・内訳を確認できる。

## 計算上の約束

- 「残高の基準日」は、その日の予定を反映する前の残高として扱います。**基準日以降（同日を含む）の予定**を反映します。既に銀行残高に反映済みの予定は二重計上しないでください。
- 基準日より前の残高は「未確定」。全体合計は全てのユーザー・口座の基準日が揃った日以降に計算されます。
- 同じ日付に複数の入出金がある場合は、すべて反映した**その日の終わりの残高**を表示します。日中の一時的な資金ショートは判定しません。
- カレンダー内の「万・億」表記は概算です。詳細欄には必ず正確な金額が表示されます。
- 入力途中の内容もブラウザのlocalStorageに保存します。別端末へ自動同期しません。バックアップはJSONの入出力（画面下の折り畳み欄）。
- 旧版の月単位データ（`jittoku.cashflow.v1`）は消さずに残しますが、年月だけで日付が不明なため自動移行しません。新版では別の保存キー `jittoku.cashflow-calendar.daily.v2` を利用します。
- 毎月繰り返し入力はシンプル版では廃止。必要な予定を日付指定で追加します。

## テスト

Node.js 18+ で、追加のnpmパッケージなしに：

```sh
node --test cashflow-calendar/test/*.test.mjs
```

ブラウザ確認：Chromiumの390px幅でユーザー3件、金額・予定入力、日付別の赤字化／回復、表示対象・月切り替え、横スクロールなし、JavaScriptエラーなしを検証。
