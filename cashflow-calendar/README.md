# ジットク 資金繰りカレンダー

将来の現金残高を月単位で予測するツール。既存の `/cashflow/`（今月お金足りる？）とは独立しています。

- `index.html`：画面
- `assets/style.css`：ジットクの配色に合わせたスマートフォン向けUI
- `src/app.mjs`：登録・編集・削除・月次表示・グラフ・localStorage
- `src/core.mjs`：収支・残高・繰り返し計算・検証
- `src/csv.mjs`：CSVの入出力（UTF-8 BOM、定期設定・期首残高・対象者名の復元）
- `test/`：Node.js標準テスト。追加依存なし

## テスト

```sh
node --test cashflow-calendar/test/*.test.mjs
```

本サイトは静的ファイル配信のみで動作し、ビルド工程は不要です。

## 注意点

- 保存先はブラウザのローカルストレージ（自動同期なし。データ消去で失われるためCSVのバックアップを推奨）
- 毎月の入出金を月初から月末までの集計として扱います。同一月内で入金と支払のどちらが先かは判定しません
- 期首残高が一方でも未設定の場合、ふたり合計の残高は「未確定」と表示
- 対応年月1900〜2200年、最大2,000登録・毎月繰り返しは最長50年
